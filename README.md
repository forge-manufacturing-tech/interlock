# Interlock

AI assisted collaboration platform for manufacturing tech transfer.

## Development Setup

This repository uses [devcontainers](https://code.visualstudio.com/docs/devcontainers/containers) to help with development.

### 1. Install Docker

Install docker on your machine. You can download it from [docker.com](https://www.docker.com/products/docker-desktop/).

For Linux machinse:

```bash
sudo apt install docker.io
```
